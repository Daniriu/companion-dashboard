# Companion Dashboard

PWA neutral y privada a nivel de datos para GitHub Pages. Incluye dashboard, fases estimadas por color, recomendaciones generales, calendario y configuración local.

## Privacidad

La fecha base y la duración del ciclo se solicitan en el primer uso y se guardan únicamente en `localStorage`. No hay cuentas, servidor, analítica, API ni sincronización. El repositorio no contiene nombres, fechas personales, mensajes privados ni datos de terceros.

`localStorage` no equivale a cifrado: cualquier persona con acceso al dispositivo y al navegador podría leer esos datos. Usa **Borrar todos los datos locales** para eliminarlos.

## Fases y limitaciones

Las fases de menstruación, folicular, ovulación y lútea se muestran como estimaciones basadas únicamente en la fecha base y la duración configurada. La ovulación estimada no confirma que haya ocurrido ovulación y no debe utilizarse como método anticonceptivo ni para decisiones clínicas. Los ciclos y sus fases pueden variar entre personas y entre meses.

## Publicar con GitHub Pages

1. Abre **Settings → Pages**.
2. Selecciona **Deploy from a branch**.
3. Elige `main` y `/ (root)`.
4. Guarda y abre la URL que GitHub muestre en esa sección.

## Instalar en iPhone

1. Abre la URL publicada en Safari.
2. Pulsa **Compartir**.
3. Selecciona **Agregar a pantalla de inicio**.
4. Confirma con **Agregar**.

## Uso

- Configura fecha base y duración en el primer uso.
- Consulta la fase estimada, el color, el progreso y las recomendaciones generales.
- Edita los valores desde **Configuración**.
- Usa **Borrar todos los datos locales** para reiniciar.

## Alcance

Las recomendaciones son orientación general de bienestar y no sustituyen valoración ni consejo médico.
